# docs

- `TRAJECTORY_GUIDE.md` — how to use and read the Trajectory layer, the model's formalism, and study-design notes for testing it.
- `RMTI_Oncoclastics_Step_by_Step_Guide.pdf` — 9-page guide to entering values into the equations (core, two senses of ρ, time-indexed), with worked examples, a where-to-type page for Python, the sandbox and the workbook, common mistakes and a printable blank worksheet. All values are samples or published cohort inputs, not validated; every number in it was computed by, and checked against, the repository code.
- `RMTI_Calculator_Explainer_v2.3.0.docx` — column-by-column explainer for the HCC calculator, including the Trajectory sheet with a worked example.
- `PAPER_SUPPORT.md` — software citation, code-and-data availability statement, map from each reported number to the code that reproduces it, notes on blinded review, pre-submission checklist.
- `reproduce_expected_output.txt` — stored output of `rmti-python/reproduce.py`; `--check` compares against it.
- `LICENSE-DOCS.md` — licence history (everything is Apache 2.0).
